# Apocalyptic prototype 03: subtle low percussion texture

[Play prototype 03](https://chatgpt.com/library?file_id=libfile_8866da913e648191b6561403113dc942&account_id=personal).

Dylan finds version 02 substantially better and asks for a tiny amount of additional drum texture, with nothing too high pitched. This version adds twelve sparse low hide-drum accents while retaining the fifty main drum strikes, bass and supporting fifths. The new shell is tuned down one octave, with short decay and a dark 65–1,100 Hz mix band. Its active target RMS is 14.5 dB below the main drums. First accents appear around 0:07–0:09. The middle reduction remains sparse.

The new layer uses a third compact drum state from the existing DSP, not a sample or a melodic voice. Native bass/body/main-drum stems are bit-identical to version 02. Their mix gains, room and master gain are retained. Peak melodic occupancy remains three voices; the player’s lead role remains empty. WAV/decoded MP3 checks pass without clipping or non-finite samples. Duration is 77.111 seconds; peak -2 dBFS; RMS -17.51 dBFS. Listening acceptance remains required.

The tools/research/apocalyptic_prototype_03.c standalone host renderer and mix_apocalyptic_prototype_03.py reproduce the audition in the same way as version 02. This remains a scored desktop sound/arrangement prototype. Installed firmware is unchanged.
