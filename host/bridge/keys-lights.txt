# the 2 x 6 buttons are the FM-1's by place (matrix: OCT- 0, OCT+ 1, FX 2, SEL 3, ENV 4, LFO 5, EDIT 6, GLO 7,
# HOME 8, SAVE 9, ARP 10, SEQ 11, PLAY 12, REC 13): top row ARP NOTE-REPEAT SCALE CHORD GLOBE BT, bottom row PATCH
# PARA FX SEQ PLAY REC
