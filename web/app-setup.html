Bring your FM-1 to a bigger screen.

Check the firmware on your FM-1, then open the display app or update to the supported PALEOTONE build.

1. Check your FM-1

Connect the powered-on FM-1 with a USB data cable. Disconnect other display or editor pages first.

Checking does not change the instrument.



Open display app


Save your music with the editor’s backup tool before updating. The installer shows progress and verifies the device after reboot.
Update PALEOTONE


You can install PALEOTONE to use this app. This replaces the existing firmware. To keep another firmware’s features, its author must integrate the display support first.
Review PALEOTONE installation




2. Use the display
The app renders the firmware’s graphics locally. Sound stays on the instrument. Expanded mode has two independent pages; hold HOME and tap OCT− for the left side or OCT+ for the right.
Use a browser with USB MIDI and SysEx support, such as desktop Chrome/Edge or Android Chrome.


Have a firmware file instead?
Check a .fwsc package locally. The file stays in your browser. This does not patch or install it.


Why can’t any firmware be patched automatically?
The device sends structured state, not screen images. Each supported firmware needs state-export hooks and an app-side copy of its renderer. The USB updater cannot read back an arbitrary installed firmware image. An identity number alone does not identify all custom firmware variants.
