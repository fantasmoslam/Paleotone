Prehistoric synth for the M-VAVE FM-1

Early alpha. PALEOTONE is experimental firmware. An install can leave the FM-1 unable to start and in need of recovery. Back up your projects first, keep a known-good firmware, and read the recovery notes below.

Install

  1. Back up: open the editor, connect the FM-1 and save a backup. The installer doesn't make one.
